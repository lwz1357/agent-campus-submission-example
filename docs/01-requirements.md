# 需求理解
| 项目 | 定义 |
|---|---|
| 用户 | 需要脚本初稿的创作者 |
| 价值假设 | 减少从资料到脚本的整理时间；尚未测量商业收益 |
| 输入 | 主题、用户、平台、目标视频时长、风格、产品 ID |
| 输出 | 状态、镜头、字幕、时长、引用、风险与执行步骤 |
| 范围 | 本地 CLI、合成资料、确定性模板 |
| 不包含 | 真实模型、视频生成、联网检索、真实发布 |
| 基础验收 | 正常请求完成；缺字段追问；无资料不编造；工具失败返回明确状态 |
| 效果边界 | 30 秒是视频目标时长，不是生成延迟承诺 |

产品事实来自 data/materials.json。原型仅验证交付链路，不能证明脚本创意或商业价值。
